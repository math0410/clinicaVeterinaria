
# 🐾 Clínica Veterinária

Sistema web desenvolvido para uma **Clínica Veterinária**, com o objetivo de apresentar os serviços oferecidos pela clínica e proporcionar uma experiência simples e intuitiva aos usuários.

## 📋 Sobre o Projeto

O projeto consiste em uma página web responsiva para uma clínica veterinária, desenvolvida utilizando tecnologias de front-end.

A aplicação possui uma interface moderna e adaptável para diferentes tamanhos de tela, permitindo que os usuários conheçam a clínica, seus serviços e tenham acesso às principais informações.

## ✨ Funcionalidades

- 🏠 Página inicial
- 🐶 Apresentação da clínica
- 🩺 Exibição dos serviços oferecidos
- 👨‍⚕️ Informações sobre profissionais
- 📞 Área de contato
- 📱 Layout responsivo
- 🎨 Interface moderna e intuitiva
- 🧭 Navegação entre as seções da página

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura das páginas
- **CSS3** — Estilização e personalização
- **JavaScript** — Interatividade e funcionalidades
- **Bootstrap** — Framework utilizado para responsividade e componentes visuais
